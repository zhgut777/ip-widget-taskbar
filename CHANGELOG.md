# История изменений

## 2.0.0

Полная переработка с нуля (пакет `ipwidget` вместо одного файла), только плашка
на панели задач — режим «карточка на рабочем столе» убран.

### Новое
- Обновление **при смене сети** (VPN, Wi-Fi, выход из сна) и повторы с нарастающей
  паузой после сбоя.
- Подсветка смены IP/страны и «ожидаемая страна» (плашка краснеет при несовпадении).
- Подсказка при наведении: город, провайдер, IPv4 и IPv6, время обновления, источник.
- Пометка устаревших данных (плашка тускнеет), прежние данные не затираются сбоем.
- Поиск свободного места на панели через UI Automation (видит «Пуск», значки,
  «Виджеты» и трей Windows 11); выбор расположения.
- Английский и русский интерфейс, английские названия стран.
- Возвращается после перезапуска проводника.
- Тесты, CI на GitHub Actions, воспроизводимая сборка, MIT-лицензия.

### Значок и ресурсы
- Новый значок приложения (глобус с зелёной точкой), рисуется скриптом
  `packaging/make_icon.py`; для 16–32 px — упрощённый рисунок.
- CPU в простое ≈ 0,4 % → ≈ 0,17 %: обход панели через UI Automation в покое раз в 30 с.
- Рабочий набор ≈ 48 МБ → ≈ 10–14 МБ: сброс неиспользуемых страниц после работы.
- exe 26,8 МБ → 15,4 МБ: исключены лишние модули, `--optimize 2`.

### Быстрее реакция на VPN
- Пауза после смены сети 4 с → 1,2 с, минимальный интервал между обновлениями по событиям
  сети 8 с → 2 с; если IP ещё прежний, дважды перепроверка через 3 с.
- Подсветка смены IP/страны теперь 10 секунд (было 45).

### Исправлено
- Повреждённый флаг навсегда оставался в кэше — теперь проверяется как PNG и
  скачивается заново.
- Длинный IPv6 растягивал плашку за предел и налезал на значки — теперь сокращается.
- Неверный `config.json` мог не дать запуститься — теперь значения проверяются.
- Журнал рос без ограничений — теперь ротация (до ~0,75 МБ).
- «Копировать IP» при отсутствии данных затирал буфер обмена пустой строкой;
  при сбое `SetClipboardData` утекала память.
- Базовая линия текста зависела от букв в названии страны («прыгала» у «Россия»).
- Тёмная кайма по краям букв из-за двойного умножения на альфу.
- Гонка данных между потоком запроса и интерфейсом (`_busy`).
- Размер плашки считался по системному DPI, а не по монитору панели задач.
- Тема по цвету пикселя «моргала» при прозрачной панели — основной источник теперь
  реестр, пиксели только с гистерезисом.

### Безопасность
- Убран запасной источник по HTTP (`ip-api.com`); только HTTPS с проверкой
  сертификата. Ответы проверяются; код страны не попадает в путь/URL без проверки.
- Честный User-Agent с версией вместо имитации браузера.

### Совместимость
- Файл настроек тот же (`%APPDATA%\IPWidget\config.json`), лишние ключи v1 отбрасываются;
  автозапуск использует то же имя в реестре.
- v1 и v2 используют разные мьютексы: перед запуском v2 закройте v1.
